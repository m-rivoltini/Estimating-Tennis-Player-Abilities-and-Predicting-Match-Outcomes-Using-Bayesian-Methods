# Bayesian-Modelling-in-Tennis
This repository contains the code and additional materials pertaining to my undergraduate dissertation entitled Bayesian Modelling in Tennis. All additional files required to run the R scripts in this repository have been included in their respective folders, except for the jagsUI outputs which were too large to upload to GitHub. For a complete collection of outputs, kindly refer to the following OneDrive link: https://1drv.ms/f/s!Arnv1891rVl5g4ZVwoMHhVRH9WMtrA?e=4VsfUa. This link contains MCMC convergence diagnostics as well as summary statistics of the posterior distributions of all parameters. Due to large file sizes, it is recommended to download the files on your local machine and open them using a lightweight PDF viewer, such as Skim: https://skim-app.sourceforge.io/ or the Google PDF viewer.
